森のおうち — ほおばまきちゃんとなかまたち

【すぐ遊ぶ】
ZIPを解凍して index.html をブラウザで開いてください。
画像・動作を1つのHTMLにまとめています。インターネット接続不要です。

【GitHub Pagesで公開】
1. GitHubに新しい公開リポジトリを作成（例：mori-no-ouchi）。
2. ZIPを解凍した index.html と .nojekyll をリポジトリの一番上にアップロード。
3. mainブランチにコミット。
4. Settings → Pages → Source: Deploy from a branch。
5. Branch: main、フォルダ: / (root) を選び Save。
6. 公開完了後にPages画面に表示されるURLを開く。

【操作】
4人をタップすると反応します。
🍄あそぶ（きのこ採り）：部屋に現れた8個をみんなで集めます。採り終えると自由行動に戻ります。
🍪おやつ・☾おひるね・✧おまかせに切り替えできます。
ひとやすみボタンで一時停止・再開します。

【編集用ソース】

このsourceフォルダを公開用index.htmlに追加する必要はありません。
